# Roadmap — точная синтетическая симуляция двигателей

Цель: **полная процедурная генерация звука двигателя, неотличимая от реальной, с конструктором двигателей** — без записей, без нейросетей, без датасетов.

Приёмка: `python tools/quality_gate.py` · `python -m pytest tests -q` (44) · `python -m simulator --selftest`
Финальная метрика каждого этапа: слепое A/B против записей реальных моторов (для проверки, не обучения) — «синтетику нельзя стабильно угадать».

## ✅ Готово

### Фундамент (этапы 0–3)

- [x] **Этап 3** — фазовая привязка: `firing_cycles` (unwrapped) → `crank_locked`; backfire/лимитер садятся на свой цилиндр

### Нативное ядро + скорость (этапы 5, 4, 6)
- [x] **Этап 5** — C++ DSP-ядро (`_dspcore.pyd`, MSVC): секционированная FFT-свёртка Гарднера, Comb, master; numpy-фолбэк — тот же алгоритм, паритет 1e-15; rtf V8 3.1× → 6×+

### Физика (этап 7)
- [x] **Wiebe per-cylinder** — окно 75° на фазе каждого цилиндра; сохранение энергии 1.008 (зеркальная дискретная норма); `torque_envelope` импульсный, отчёт — сглаженное среднее; кривая момента/BMEP = mean-value (тест 8%); 13.8-л дизель держит холостой, зажигание off глохнет, лимитер не разгоняется

### Аудит-фиксы (4 раунда по измерениям)
- [x] `_flow_shape` per-path (СВЧ-мусор), `_bank_gain` 1/n_paths (глубина), Wiebe-аккумулятор при cut
- [x] front_gain 0.85/√n, тики ×1/√n×load-маска, clatter order-1 (маракасы: полоса 3–12 кГц −46%)
- [x] torque_pulse-сглаживание (алиасинг 129 скачков/с → модем), GC-freeze в GUI, шоты на офлайн-блоке
- [x] Q-конус мод (растущий Q = нефизично → симметричный конус 500 Гц), наклон шума импульса (−6 dB/окт), resonance_compress 2:1, калибровка = рантайм-цепь (7325 rpm: 39% → 8.9% в колене)

### Быстрый фикс: asset-режим (лаг убит архитектурно)
- [x] **LoopBank** — 5 слоёв (idle/mid/wot/coast/limiter) рендерятся офлайн-рендерером в фоне (3 потока, W16: 9 c), пик-нормализация −2 dBFS, калибровка снята с пути свитча
- [x] **LoopPlayer** — колбэк = воспроизведение: ~40 мкс/блок при дедлайне 2667 мкс (**запас ~60×**), equal-power бленд sin/cos по rpm + coast по нагрузке, AM от torque_pulse (сглаженный), heat-detune от pipe_temp, лимитер-слой поверх
- [x] **EngineAudio `mode="assets"`** — банк и шоты рендерятся в worker-потоках, GUI/аудио никогда не ждут синтез; headless-сборка для тестов
- [x] Легальность по всему свипу: пик ≤ 0.852; 0 разрывов на полном рейндже; e2e PCM чистый
- [x] 6 тестов `tests/test_asset_mode.py` (44 всего)

## ⬜ План до «невероятного качества»

### Фаза A — Газодинамическое ядро (парадигма Ange, портированная в наш C++)

Звук *возникает* из нелинейного газового потока, а не проходит через фильтры. Портируем проверенную модель [engine-sim](https://github.com/ange-yaghi/engine-sim) в `_dspcore`:

- [ ] **A1. `GasSystem` в C++** — state {n_mol, V, E_k, momentum[2], mix}; c() из энергии, давление, choked-flow коэффициенты (кэш на степени свободы). ~150 строк ядра.
- [ ] **A2. `flow()` между системами** — двусторонний сжимаемый поток: перенос n/E/импульса/смеси, сохранение во всех шагах, clamp на pressure-equilibrium max flow.
- [ ] **A3. `dissipateExcessVelocity` + `updateVelocity`** — кламп сверхзвука в тепло (нелинейное заострение = rasp на газу, то, что tanh подделывал), 2D-импульс из динамики давления на гранях.
- [ ] **A4. Интеграция с нашей физикой** — цилиндр: Wiebe-энергия + профиль подъёма клапана из пресета → `flow(cyl→runner)`; crank-clock уже есть (`firing_cycles`). 49 пресетов работают без изменений формата.
- [ ] **A5. Тракт из пресета**: раннер (длина/сечение) → коллектор-junction (сохранение импульса, интерференция крест-порядка рождается сама) → труба (velocityDecay) → глушитель-секции → атмосфера; выходной поток = аудио.
- [ ] **A6. Тюнинг-контракты** — длина/сечение/глушитель из TOML меняют звук физически; C++-поток держит 44.1 кГц на <5% ядра.
- [ ] **Приёмка A** — слепое A/B: наш рендер vs [записи реальных V8/V12/I4](https://www.youtube.com/watch?v=2bJTkBsiTPc) (эталон для проверки): газодинамический rasp на WOT, кросс-плейн бурчит на холостых из интерференции, а не из подложки.

### Фаза B — Гибрид: газовое ядро + существующие слои

- [ ] **B1.** Смешивание: газодинамика = тело выхлопа; механика/тики, впуск, турбо — существующие C++-слои поверх (конволюционный движок уже есть).
- [ ] **B2.** IR-пост-обработка: микрофон/дистанция/пространство — свёртка (Ange: convolution с IR — ключ к «дорогому» звуку); наша `outdoor_ir` + distance-модель переезжают в C++.
- [ ] **B3.** Asset-режим остаётся режимом ассетов: банк рендерится из газового ядра тем же LoopBank → качество ядра доступно и live, и офлайн без изменений архитектуры плеера.
- [ ] **Приёмка B** — A/B внутри каталога: crossplane vs flatplane на одинаковых оборотах различимы на слух без метрик.

### Фаза C — «2D»-вопрос (опционально, по результату прослушивания)

У Ange «2D» = momentum[2] (0D-системы с 2D-импульсом), не сетка. Для трансверсальных мод (широкость резонанса >3 кГц):

- [ ] **C1.** 1D FDTD (TVD) на коллекторе/глушителе — где реально есть многомерность; ударные волны/steepening из геометрии. ~5× стоимости трубы, только на 2–3 сегментах.
- [ ] **C2.** Только если прослушивание фазы B скажет «резонансы узкие»: полная 2D-сетка не планируется — тонкая труба акустически 1D до ~3–4 кГц.

### Фаза D — Конструктор двигателей (цель проекта)

- [ ] **D1.** Live-параметры тракта в GUI (длина/сечение/глушитель) — звук меняется мгновенно через газовое ядро.
- [ ] **D2.** Валидация конструктора: нестандартные конфиги (I5, W16, big-bang) звучат правдоподобно без ручного тюнинга — параметров тембра в пресете становится меньше, физики больше.
- [ ] **D3.** Экспорт ассетов (WAV-слои + manifest) — уже работает, перегенерация из ядра.

### Приёмка финальная (без датасетов, без DDSP)
- [ ] Слепой A/B против ≥10 записей реальных моторов: «нельзя стабильно угадать синтетику».
- [ ] RTF live ≥ 20× (газовое ядро в C++ это даёт: ~300 флопс/сэмпл).
- [ ] Задержка ≤ 10 ms на любом пресете, 0 андерранов под нагрузкой GUI.
