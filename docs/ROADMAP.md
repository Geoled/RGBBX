# Roadmap — точная синтетическая симуляция двигателей

Цель: **полная процедурная генерация звука двигателя, неотличимая от реальной, с конструктором двигателей** — без записей, без нейросетей, без датасетов.

Приёмка: `python tools/quality_gate.py` · `python -m pytest tests -q` (44) · `python -m simulator --selftest`
Финальная метрика каждого этапа: слепое A/B против записей реальных моторов (для проверки, не обучения) — «синтетику нельзя стабильно угадать».

## ✅ Готово

### Фундамент (этапы 0–3)
- [x] **Этап 0** — `tools/quality_gate.py` (rtf, sr_dev, lufs, latency, crank_deg, phase_lock, core, paths, wiebe) + регрессионные тесты
- [x] **Этап 1** — LUFS-калибровка по операционному свипу + safety limiter (C1-колено): lufs_spread ≈ 0.2 dB по каталогу
- [x] **Этап 2** — инвариантность к частоте дискретизации: `taps_for` (окно в секундах), `noise_burst` (спектральный ресемплинг), октавные полосы → sr_dev 1.5–2.1 dB
- [x] **Этап 3** — фазовая привязка: `firing_cycles` (unwrapped) → `crank_locked`; backfire/лимитер садятся на свой цилиндр

### Нативное ядро + скорость (этапы 5, 4, 6)
- [x] **Этап 5** — C++ DSP-ядро (`_dspcore.pyd`, MSVC): секционированная FFT-свёртка Гарднера, Comb, master; numpy-фолбэк — тот же алгоритм, паритет 1e-15; rtf V8 3.1× → 6×+
- [x] **Этап 4** — per-cylinder выхлоп: 8 полных трактов на V8, индивидуальный джиттер длин труб, стерео по банкам
- [x] **Этап 6** — задержка 170.7 ms → 8 ms (block 128 × 3, постоянная стоимость)

### Физика (этап 7)
- [x] **Wiebe per-cylinder** — окно 75° на фазе каждого цилиндра; сохранение энергии 1.008 (зеркальная дискретная норма); `torque_envelope` импульсный, отчёт — сглаженное среднее; кривая момента/BMEP = mean-value (тест 8%); 13.8-л дизель держит холостой, зажигание off глохнет, лимитер не разгоняется

### Аудит-фиксы (4 раунда по измерениям)
- [x] `_flow_shape` per-path (СВЧ-мусор), `_bank_gain` 1/n_paths (глубина), Wiebe-аккумулятор при cut
- [x] front_gain 0.85/√n, тики ×1/√n×load-маска, clatter order-1 (маракасы: полоса 3–12 кГц −46%)
- [x] torque_pulse-сглаживание (алиасинг 129 скачков/с → модем), GC-freeze в GUI, шоты на офлайн-блоке
- [x] Q-конус мод (растущий Q = нефизично → симметричный конус 500 Гц), наклон шума импульса (−6 dB/окт), resonance_compress 2:1, калибровка = рантайм-цепь (7325 rpm: 39% → 8.9% в колене)

### Быстрый фикс: asset-режим (лаг убит архитектурно)
- [x] **LoopBank** — 5 слоёв (idle/mid/wot/coast/limiter) рендерятся офлайн-рендерером в фоне (3 потока, W16: 9 c), пик-нормализация −2 dBFS, калибровка снята с пути свитча
- [x] **LoopPlayer** — колбэк = воспроизведение: ~40 мкс/блок при дедлайне 2667 мкс (**запас ~60×**), equal-power бленд sin/cos по rpm + coast по нагрузке, AM от torque_pulse (сглаженный), heat-detune от pipe_temp, лимитер-слой поверх
- [x] **EngineAudio `mode="assets"`** — банк и шоты рендерятся в worker-потоках, GUI/аудио никогда не ждут синтез; headless-сборка для тестов
- [x] Легальность по всему свипу: пик ≤ 0.852; 0 разрывов на полном рейндже; e2e PCM чистый
- [x] 6 тестов `tests/test_asset_mode.py` (44 всего)

## ⬜ План до «невероятного качества»

### Фаза A — Газодинамическое ядро (парадигма Ange, портированная в наш C++)

Звук *возникает* из нелинейного газового потока, а не проходит через фильтры. Портируем проверенную модель [engine-sim](https://github.com/ange-yaghi/engine-sim) в `_gascore`:

- [x] **A1. `GasSystem` в C++** — state {n_mol, V, E_k, momentum[2], mix}; c() из энергии, давление, choked-flow коэффициенты (кэш на степени свободы). [gascore.cpp:60](tools/soundgen/native/gascore.cpp#L60)
- [x] **A2. `flow()` между системами** — двусторонний сжимаемый поток: перенос n/E/импульса/смеси, сохранение во всех шагах, clamp на pressure-equilibrium max flow; капы T≤4000 K и 0.5·n против расходимости (первый рендер давал 1e18). [gascore.cpp:239](tools/soundgen/native/gascore.cpp#L239)
- [x] **A3. `dissipateExcessVelocity` + `updateVelocity`** — кламп сверхзвука в тепло (нелинейное заострение = rasp на газу), 2D-импульс из динамики давления на гранях. [gascore.cpp:154](tools/soundgen/native/gascore.cpp#L154)
- [x] **A4. Интеграция с нашей физикой** — цилиндр: Wiebe-энергия + косинусный профиль подъёма клапана → `flow(cyl→runner)`; crank-clock общий с моделью (`firing_cycles`); 49 пресетов без изменений формата. [gasvoice.py:195](tools/soundgen/soundgen/gasvoice.py#L195)
- [x] **A5. Тракт из пресета**: раннер (длина/сечение) → коллектор per-bank → труба → глушитель → атмосфера; вся геометрия из TOML. Измеренный главный урок: lumped-сеть — mean-value модель, она НЕ пропускает импульсы к выходу (полоса 85–115 падала до −69 dB через orifice-каскад). Архитектура исправлена на измерениях: **эксциация = сумма клапанных потоков** (несёт полный импульсный поезд: 25 Гц порядок + гармоники до −11 dB), затем **IR тракта из геометрии** (quarter-wave comb c/(4L) + банк мод + глушитель + air). [gasvoice.py:296](tools/soundgen/soundgen/gasvoice.py#L296)
- [x] **A6. Тюнинг-контракты** — batched C++ `run_excitation` (весь crank/valve/Wiebe цикл нативно, 15–23× realtime); длина трубы слышима (тест), нагрузка меняет звук (тест). 56 тестов всего зелёные. [gascore.cpp:492](tools/soundgen/native/gascore.cpp#L492)
- [x] **Приёмка A** — I4/V12 кросс-тесты порядка зажигания пройдены; стабилизировано на всём каталоге (smoke-тест всех пресетов через gas-банк).

### Фаза B — Гибрид: газовое ядро + существующие слои

- [x] **B1.** Тракт IR собирается из тех же примитивов что процедурный голос (comb_kernel, resonator_kernel, lowpass, air) — общая тембральная основа, A/B честный.
- [x] **B2.** Радиационная цепь: 20 Hz Butterworth AC-связь (микрофон), per-block нормализация (AGC-качание кросс-блочного фолловера исправлено измерением).
- [x] **B3.** `LoopBank(engine="gas")` — банк рендерится из газового ядра тем же плеером; `EngineAudio(engine=...)` — переключатель; тумблер **GAS CORE** в GUI (live A/B, `reload_audio()`); шоты/турбо/стук — существующие слои поверх. Пик по свипу ≤ 0.694 (легально).
- [x] **Приёмка B** — gas-банк через плеер: rms 0.24, 0 разрывов; каталог-смоук всех 49 пресетов через gas-банк зелёный.

### Фаза C — «2D»-вопрос

У Ange «2D» = momentum[2] (0D-системы с 2D-импульсом), не сетка. momentum[2] реализован в A1 (dx/dy на гранях). Трансверсальные моды через FDTD отложены до прослушивания фазы B — тонкая труба акустически 1D до ~3–4 кГц.

- [x] **C0.** momentum[2] в ядре (соответствие Ange-модели).
- [ ] **C1.** 1D FDTD на коллекторе/глушителе — по результату прослушивания.

### Фаза D — Конструктор двигателей (цель проекта)

- [x] **D1.** Геометрия тракта в TOML (pipe_length, runner, muffler, modes) уже слышима через газовое ядро — тест `test_pipe_length_shifts_the_tone` и `test_tract_geometry_is_audible` пинуют контракт; live-тумблер GAS CORE в GUI.
- [x] **D2.** Валидация: одиночка/I4/V8/V12 стабильны и слышимы; порядок зажигания follows цилиндрам (кросс-тест I4 vs V12); весь каталог прогоняется через gas-банк (smoke).
- [ ] **D3.** Экспорт ассетов из газового ядра (газ-банк → WAV-слои + manifest) — банк уже отдаёт те же entries, осталась кнопка экспорта.

### Приёмка финальная (без датасетов, без DDSP)
- [ ] Слепой A/B против ≥10 записей реальных моторов: «нельзя стабильно угадать синтетику» — **требует вашего прослушивания** (WAV-рендеры обоих ядер готовы к сравнению).
- [x] RTF live: газовое ядро 15–23× (batched C++), asset-колбэк ~40 мкс (запас ~60×).
- [x] Задержка ≤ 10 ms на любом пресете (8 ms профиль), 0 андерранов по построению (синтеза в колбэке нет).
