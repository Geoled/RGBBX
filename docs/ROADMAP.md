- [x] **Лаг — три источника**:
  - [x] Tk-GUI строил `EngineAudio` на главном потоке: 2.6–4.3 s полной заморозки окна на каждом свитче (W16: калибровка 0.8 s + банк шотов 2.7 s) — вынесено в worker-поток с токеном отмены (`_open_audio_async`)

## ✅ Раунд 3: «dial-up» (по третьему аудиту, проверен весь проект)

- [x] Проверено всё: pyd свежее cpp (18:46 vs 16:59), нативный/нумпевский рендеры идентичны до 2e-15, PCM-выход без разрывов (0 жёстких скачков, границы блоков не хуже внутренностей), единственный «тихий» участок — 23 ms прогрева конволверов при старте
- [x] **Причина 1 — алиасинг `torque_pulse`**: публикуется на 120 Гц, а пики Вибе ~6 ms → измерено **129 скачков >0.3/с** попадает в усиление зажиганий = AM-грязь ~120 Гц (она же портила график). Фикс: сглаживание в голосе по времени с τ = половина периода зажигания — трек пика без ступеней
- [x] **Причина 2 — бимодальный колбэк** (тот самый dial-up): `CONV_GRAIN=256` рендерил 256 кадров каждый второй 128-кадровый вызов (1577 us vs 19 us чередование); тяжёлая половина у дедлайна, любой джиттер планировщика → регулярный андерран каждые 5.3 ms. Фикс: зерно = блок, чередование 1.01 (было 0.01)
- [x] **Причина 3 — GC в аудиопотоке**: рендер аллоцирует numpy-времянки каждый блок; gen-2 коллекция = мульти-мс пауза в 2.67-мс колбэке, периодическая по скорости аллокации. Фикс: `gc.collect()+freeze()+set_threshold(50000,50,50)` в обоих GUI при старте
- [x] W16-класс (≥10 цилиндров): live-блок 256 в обоих GUI — измерено 2700 us при дедлайне 5333 (запас 2.0×, 0 андерранов из 300)
- [x] Проверки: pytest 38/38, selftest 0 FAIL, gate зелёный; PCM-скан чистый

## ✅ Раунд 4: глубокий аудио-аудит (20 точек каталога, спектр/огибающая/гармоники)

- [x] **Аудит-протокол**: 20 операционных точек × {крест-фактор, спектральная плоскость, AM-пик, hf/mid, LUFS, пик} — структурные выводы: AM-огибающая на порядке зажигания верна на всех пресетах (28 Гц у I4 на холостых, 53 у V8, 300 у V12 на 4500), линейный спектр правильный (flatness 0.005–0.05), турбина — шум (0.367, физично)
- [x] **Баг 1 — HF-эмфаз шума blowdown**: белый `noise_burst` в импульсе имел **+7.7 dB** энергии в 4–8 кГц над 0.5–1 кГц → гармоники порядка зажиганияplatо (1.7 dB/гармоника на 5000 rpm при физических −3..−6) = металлический гребёнчатый зуд. Фикс: однополюсный НЧ на шуме импульса (−6 dB/окт, физика: газ рождается у клапана, порт/раннер его фильтрует). [dsp.py:714](tools/soundgen/soundgen/dsp.py#L714)
- [x] **Баг 2 — тики ГРМ на холостых без маскировки**: слой тиков держал 6–12 кГц на уровне −7 dB от тела ноты (реальные холостые: −15..−25) = шейкер. Фикс: маска по нагрузке `0.45+0.55*load` + уже сделанная нормализация 1/√n_cyl. Каталог: −7 → −12..−15 dB
- [x] **Баг 3 — Q-профиль мод вверх ногами (весь каталог!)**: все пресеты имеют растущий Q с частотой (1.6@84 Гц → 2.85@2.7 кГц) — противоположно физике (стенки/глушитель душат высокие моды). Когда порядок зажигания наезжал на высокодобротную моду, точка свипа выдавала +8 dB → калибровочный гейн давил её в лимитер (39% сэмплов в колене @7325 rpm, крест-фактор 2.8 = «раскатанное» звучание). Фикс: симметричный конус вокруг 500 Гц — Q×(500/f)^0.25 (клэмп 0.5..3.0), гейн×(500/f)^(1/3). Первая односторонняя версия усилила НЧ-моды и ухудшила 1500 rpm (42% → 50%) — конус обязан быть симметричным. [dsp.py:427](tools/soundgen/soundgen/dsp.py#L427)
- [x] **Баг 4 — калибровка не знала о рантайм-нелинейностях**: `measured()` не включала resonance_compress → гейн не соответствовал реальной цепи. Фикс: зеркалирует весь мастер-цепь (компрессор → сатурация → лимитер)
- [x] **Улучшение — `resonance_compress`**: 2:1 выше −9 dBFS до лимитера. Резонансные rpm (порядок зажигания на моде) — реальная физика, но отдавать их лимитеру напрямую = пампинг. Компрессор берёт +4 dB, лимитер возвращается к роли гаранта. [dsp.py:267](tools/soundgen/soundgen/dsp.py#L267)
- [x] **Пресет-тюн откащен до 1.20**: `combustion_gain 1.35` дублировал order_boost и вгонял 1500 rpm глубже в лимитер
- [x] **Контракт теста обновлён**: среднее свипа −17..−12.5 LUFS (цель −14, допуск на резонансные точки), hottest ≤ −4 (физика резонанса, не «плоская громкость»), пик ≤ 0.9
- [x] Итог раунда: pytest 38/38, selftest 0 FAIL, gate зелёный; idle hf/mid −7 → **−12..−15 dB** (каталог), 7325 rpm: 39% → **8.9%** в колене, гейн калибровки согласован с рантайм-цепью
