# Сборка портативной версии под Windows

Цель: получить папку, которую можно скопировать на другой ПК (флешка, сеть) и
запустить двойным щелчком — **без установки Python и без прав администратора**.

---

## 1. Что получится

```
dist/EngineLab/
    EngineLab.exe          приложение (без консольного окна)
    EngineLabDebug.exe     то же самое, но с консолью — для диагностики
    _internal/             интерпретатор Python, DLL, шрифты imgui,
                           пресеты и нативный DSP-модуль
dist/EngineLab-portable.zip   то же самое одним архивом
```

Внутри `_internal` уже лежит всё, что нужно: `numpy`, `scipy`, `imgui_bundle`
(с его нативными библиотеками и шрифтами), `moderngl`, `sounddevice`
(PortAudio), `soundfile` (libsndfile), `Pillow`, пресеты двигателей и
`_dspcore*.pyd`.

Пресеты лежат в `_internal/tools/soundgen/presets/*.toml` — их можно
добавлять/править прямо в собранной папке, приложение подхватит их при
следующем запуске.

---

## 2. Что нужно на машине, где вы **собираете**

| | |
|---|---|
| ОС | Windows 10/11, x64 |
| Python | 3.12–3.14, x64 (сейчас проект проверен на 3.14) |
| Зависимости | `pip install -r requirements.txt` |
| Сборщик | `pip install pyinstaller` (или `pip install -r requirements-dev.txt`) |
| GPU | OpenGL 3.3 (обычный драйвер NVIDIA/AMD/Intel; нужен только для 3D-вида) |

На машине, где вы **запускаете**, из этого списка не нужно ничего.

---

## 3. Сборка

```bat
build_exe.bat
```

Скрипт делает три вещи:

1. проверяет, что установлен PyInstaller (если нет — ставит из
   `requirements-dev.txt`);
2. прогоняет `pytest tests` и **не собирает**, если тесты упали;
3. запускает `pyinstaller engine_lab.spec` и кладёт результат в `dist\`.

С архивом:

```bat
build_exe.bat --zip
```

Вручную, без скрипта:

```bat
python -m PyInstaller --noconfirm --clean engine_lab.spec
```

Сборка занимает 2–5 минут, готовый комплект — примерно 196 МБ
(основной вес: scipy с OpenBLAS, numpy, imgui_bundle); zip-архив — около 84 МБ.

Проверено на этой машине (Python 3.14, Windows x64): `EngineLabDebug.exe
--selftest` проходит все проверки и печатает `DSP core: native`,
`EngineLab.exe --capture file.png` рендерит кадр через moderngl, окно
приложения открывается без ошибок в stderr.

### Почему onedir, а не один .exe

Сборка «в один файл» (`--onefile`) распаковывает всё во временную папку при
каждом запуске: старт становится на 3–10 секунд дольше, а антивирусы чаще
ругаются на самораспаковывающиеся exe. Для приложения с нативным `.pyd` и
каталогом пресетов папка надёжнее. Если всё же нужен один файл — добавьте
`--onefile` в `EXE(...)` в `engine_lab.spec`, но это не рекомендуется.

## 4. Перенос на другой ПК

1. Скопируйте **всю папку** `dist\EngineLab` (не только `EngineLab.exe` —
   без `_internal` он не запустится).
2. Запустите `EngineLab.exe`.

При первом запуске:

* Windows SmartScreen может показать «Windows защитила ваш компьютер» —
  это нормально для неподписанного exe: «Подробнее» → «Выполнить в любом
  случае». Подпись кода (code signing) убирает это предупреждение, но требует
  сертификата.
* Первый запуск каждого пресета рендерит банк лупов: 2–10 секунд (I4 ~2.5 с,
  W16 ~8 с). Дальше банк берётся из кэша за ~0.01 с.
* Кэш лежит в `%LOCALAPPDATA%\EngineLab\loopbank` (не в папке программы),
  ~2.3 МБ на пресет, хранится 12 последних. Удаление папки = полная
  перерисовка банков, ничего не ломается.
* Права администратора не нужны; ничего в реестр не пишется.

Проверка на новом месте без окна:

```bat
EngineLabDebug.exe --selftest
EngineLabDebug.exe --list
EngineLab.exe --preset v8_crossplane
```

`--selftest` проверяет физику, `--list` — что пресеты и `soundgen` видны
из бандла. `EngineLabDebug.exe` отличается от `EngineLab.exe` только наличием
консоли, код тот же.

---

## 5. Требования на целевом ПК

* Windows 10/11 x64 (см. раздел про Windows 7 ниже);
* видеодрайвер с OpenGL 3.3 — иначе 3D-вью не создастся (звук и физика при
  этом сами по себе работают, но окно создаётся вместе с вьюпортом, поэтому
  на «Microsoft Basic Display Adapter» приложение не откроется);
* любая звуковая карта: сначала пробуется WASAPI через PortAudio, затем
  WinMM-фолбэк (`--audio-backend winmm`).

## 6. Windows 7 — почему не получится «просто собрать»

Текущий стек принципиально не работает на Windows 7:

| Компонент | Минимум | Причина |
|---|---|---|
| CPython | 3.9+ | Python 3.9 перестал поддерживать Windows 7 (последняя версия для Win7 — 3.8.10) |
| `imgui_bundle` 1.93 | Python ≥ 3.10 | колёса под 3.8 не выпускаются |
| `numpy` 2.5 | Python ≥ 3.12 | более старые numpy можно, но не с текущим кодом |
| `tomllib` | Python ≥ 3.11 | используется для чтения пресетов (на 3.8 нужен `tomli`) |

То есть «поддержка Win7» — это не флаг сборки, а отдельная ветка проекта:
Python 3.8.10 x64, старые `imgui_bundle`/`moderngl`/`numpy`/`scipy`, замена
`tomllib` на `tomli`, проверка API `immapp`/`hello_imgui` (в старых версиях
он отличался), пересборка `_dspcore` под `cp38` и PyInstaller 5.x. Это
несколько дней работы с реальным риском, что старый `imgui_bundle` не
поддержит используемые вызовы.

Практичный вариант: целевая платформа — Windows 10/11 x64. Если Win7
действительно обязателен, это нужно делать отдельной legacy-сборкой, а не
пытаться собрать текущий код «пониже».

## 6.1. Нативный `_dspcore` и версия Python

`_dspcore` — обычное расширение CPython, оно привязано к версии интерпретатора
(сейчас в репозитории лежит `_dspcore.cp314-win_amd64.pyd`). В собранном
комплекте интерпретатор свой, поэтому менять ничего не нужно: сборка на
Python 3.14 даёт pyd для 3.14.

Если собирать другим Python (например, 3.12), подходящего `.pyd` не будет:
приложение запустится и будет работать, но на numpy-фолбэке — рендер банка
примерно в 2 раза медленнее, звук идентичен. Пересобрать под свою версию:

```bat
python tools\soundgen\native\build.py --force
python -m PyInstaller --noconfirm --clean engine_lab.spec
```

Проверить, что нативный модуль подхватился: `EngineLabDebug.exe --selftest`
печатает `DSP core: native` (или `numpy (причина)`).

## 7. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| `Failed to execute script 'launcher'` | скопирован только exe без `_internal` — копируйте папку целиком |
| Окно не открывается, в консоли `moderngl`/`OpenGL` | драйвер GPU без OpenGL 3.3, обновите драйвер |
| Нет звука, в статусе `audio error` | запустите `EngineLabDebug.exe` и посмотрите текст; попробуйте `--audio-backend winmm` |
| Первый пресет «молчит» 5–10 секунд | идёт рендер банка, это ожидаемо; дальше кэш |
| Антивирус удаляет exe | ложное срабатывание на PyInstaller; добавьте папку в исключения или подпишите exe |
| Нужно проверить, что нативный DSP загрузился | в статусе/`--selftest` будет `native`, иначе `numpy (...)` |

---

## 8. Что не попадает в сборку

`tests/`, `docs/`, `_tmp/`, `_sg_*`, `out/`, `.git` — всё это нужно только
для разработки. Старые WAV-ассеты из `tools/soundgen/out` приложению не
нужны: банки рендерятся из пресетов при первом запуске и кэшируются.
