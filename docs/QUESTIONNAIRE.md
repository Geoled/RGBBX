## Блок 5. Технический формат

**5.1. Частота дискретизации:**
- a) 48000 Hz **(по умолчанию)**
- b) 44100 Hz
- c) 22050 Hz (для мобилок, легче)

**5.2. Битность:**
- a) 16-bit PCM **(по умолчанию, требует меньше места в Roblox)**
- b) 24-bit PCM

**5.3. Каналы:**
- a) Mono — лучше для 3D-позиционирования в Roblox **(по умолчанию)**
- b) Stereo
- c) Оба (моно для 3D, стерео для интерьера/капота)

**5.4. Длина лупов:**
- a) 2–4 секунды **(по умолчанию)**
- b) 1–2 секунды (меньше файлы)
- c) 4–8 секунд (стабильнее лупы)

**5.5. Сколько слоёв на один двигатель?**
- a) 5: idle, mid, wot, coast, limiter **(по умолчанию)**
- b) 3: idle, mid, wot (экономия)
- c) 7+ с промежуточными нагрузками
